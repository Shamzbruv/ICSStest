# Rep Yuh Place asset set

- `rep-yuh-place.webp`: optimized supplied official full logo, original identity retained.
- `brand-mark.svg`: simplified emerald/gold microphone mark for small surfaces; a supporting mark, not a replacement official logo.
- `favicon.ico`, `favicon-32.png`: browser tab icons.
- `apple-touch-icon.png`: 180px iOS home screen icon.
- `icon-192.png`, `icon-512.png`: web application icons.
- `icon-maskable-512.png`: safe-zone Android maskable icon.
- `social-card.jpg`: 1200 × 630 sharing card, original logo over the stage artwork.
- `stage-backdrop.webp`: generated supporting stage graphic used on the stage and CTA sections.

Stage artwork created using the built-in image generation tool, with the supplied logo as palette reference. Brief: cinematic empty performance stage, emerald atmosphere, thin gold arcs, warm spotlights, glossy dark floor, gold microphone stand at right; clear dark center-left for the actual logo; no text, people, or recreated logo. Icons and sharing-card layout use deterministic SVG rendering.
